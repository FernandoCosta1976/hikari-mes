# UC-PERF-003 — Identify Bottleneck

**Primary actors:** Production Manager, Manufacturing Engineer  
**Supporting:** Foundry Supervisor  
**Question:** Onde está meu gargalo?  
**Status:** PROTOTYPE_BASELINE

## Required information

- throughput;
- queue/WIP context;
- Resource utilization/performance;
- repeated constraints;
- plan versus actual;
- downstream/upstream context where available.

## Outcome

The user identifies the current or recurring constraint requiring investigation.

## Rule

The prototype must not claim algorithmic bottleneck detection unless the scenario explicitly defines a demonstrative rule.
