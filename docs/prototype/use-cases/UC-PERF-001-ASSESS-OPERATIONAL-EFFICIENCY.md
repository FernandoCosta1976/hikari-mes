# UC-PERF-001 — Assess Operational Efficiency

**Primary actor:** Industrial Director  
**Supporting actors:** Production Manager, Engineer  
**Question:** Estamos sendo eficientes?  
**Status:** PROTOTYPE_BASELINE

## Required information

- OEE where applicable;
- Availability;
- Performance;
- Quality;
- plan versus actual;
- losses;
- bottlenecks;
- relevant area context.

## Main flow

1. Director views executive efficiency state.
2. HIKARI shows dominant performance indicators.
3. HIKARI highlights where efficiency is being degraded.
4. Director drills only when needed.

## Outcome

Leadership understands operational efficiency and where attention is required.

## Rule

OEE is an outcome of trustworthy execution, event and quality data, not an isolated solution.
