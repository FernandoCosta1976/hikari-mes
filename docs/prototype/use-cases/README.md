# HIKARI MES — Use Cases

Use Cases are organized by **business objective**, not by screen.

Each Use Case must contain:

- primary actor;
- supporting actors;
- business question;
- trigger;
- preconditions;
- required information;
- main flow;
- alternatives/exceptions;
- outcome;
- prototype behavior;
- exclusions;
- traceability.

A screen may support multiple Use Cases, and one Use Case may span multiple experiences.

## Reference Production Use Case IDs

1. `UC-PROD-001` — Review Short-Term Production Schedule
2. `UC-PROD-002` — Reconcile Production Orders and Scheduled Lots
3. `UC-PROD-003` — Validate Production Readiness
4. `UC-PROD-004` — Operationally Resequence Lots
5. `UC-PROD-005` — Assign Lot to Resource

These IDs are unique and must be used consistently in filenames, document titles and traceability matrices.
