# UC-PROD-003 — Validate Production Readiness

**Primary actor:** Foundry Supervisor  
**Supporting actors:** Production Leader, Technician, Quality as context requires  
**Question:** Temos condições de cumprir o plano?  
**Status:** PROTOTYPE_BASELINE

## Trigger

The operational team needs to prepare scheduled Lots for execution.

## Required information

- raw-material availability;
- Resource eligibility;
- Resource availability;
- mold/tooling context;
- Setup;
- capacity context;
- maintenance restriction;
- buffer context;
- downstream context when available.

## Main flow

1. User reviews scheduled commitment.
2. HIKARI evaluates/displays demonstrative readiness dimensions.
3. HIKARI highlights constraints/risks.
4. User opens affected Lot/Material context.
5. User understands why attention is required.
6. User proceeds to resequencing or Resource assignment.

## Outcome

The team understands whether the planned commitment is executable and which conditions require intervention.

## Rule

HIKARI supports decisions; it does not claim automatic optimal planning.
