# UC-PERF-002 — Identify Production Losses

**Primary actors:** Production Manager, Manufacturing Engineer  
**Supporting:** Foundry Supervisor, Quality  
**Question:** Quanto perdemos?  
**Status:** PROTOTYPE_BASELINE

## Required information

- downtime;
- Scrap;
- Rework;
- speed/performance loss;
- affected Resource;
- affected Lot/Material;
- time context.

## Outcome

Users can quantify and contextualize relevant production losses.

## Boundary
