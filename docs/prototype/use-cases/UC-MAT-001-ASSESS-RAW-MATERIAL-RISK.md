# UC-MAT-001 — Assess Raw Material Risk

**Primary actor:** Foundry Supervisor  
**Supporting actor:** Production Leader  
**Question:** Temos matéria-prima suficiente?  
**Status:** PROTOTYPE_BASELINE

## Main flow

1. HIKARI relates production commitment to raw-material context.
2. HIKARI highlights potential shortage.
3. User identifies affected Material/Lots.
4. User evaluates whether sequence/commitment requires intervention.

## Outcome

Raw-material risk becomes visible before it causes avoidable production disruption.

## Exclusion

HIKARI prototype does not reproduce MRP.
