# UC-EXEC-001 — Monitor Execution and Commitment

**Primary actor:** Production Leader  
**Supporting actors:** Foundry Supervisor, Production Manager  
**Question:** Estamos cumprindo o plano?  
**Status:** PROTOTYPE_BASELINE

## Required information

- active Lots;
- planned quantities;
- produced quantities;
- Dispatched Sequence;
- Actual Sequence;
- events;
- shift/day commitment;
- projected completion.

## Outcome

Users understand current execution, deviation and risk to commitment.

## Prototype note

This Use Case follows the first scheduling/readiness wireframes and should reuse the same Lot identity and lineage.
