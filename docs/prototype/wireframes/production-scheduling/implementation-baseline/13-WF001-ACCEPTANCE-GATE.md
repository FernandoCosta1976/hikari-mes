# WF-001 — Acceptance Gate
**Domínio:** fontes corretas; Lot preservado; Work Center≠Resource; Resource não inventado; Produzido≠Disponível; buffer correto; destino≠consumidor.
**UX:** pergunta dominante; Plano Hora-Hora principal; Lot selecionável; detalhe contextual; CTA preparação; Área global.
**Dados:** demo identificado; matemática coerente; Order/Lots conciliados; timestamps coerentes; versões preservadas.
**Freshness:** fonte, data da informação, última recepção/atualização e estado preservados; nenhuma próxima atualização automática ou frequência inventada.
**Visual:** aderência à imagem; sem vermelho; identidade HIKARI; timeline legível; status não só por cor.
**Arquitetura:** demo isolado; sem backend/integração/persistência; sem resolver TBD via código.
**Confidencialidade:** sem detalhes técnicos proprietários.
**Narrativa:** em ~90s explicar o que, quando, Lots, Order, freshness, buffer e próxima decisão.
