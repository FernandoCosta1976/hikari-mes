# WF-001 — Information Architecture
Ordem:
1. Contexto: Área, período, atualização.
2. Resposta: quantidade, Lots, destinos.
3. Confiabilidade: Balancing, versão, timestamps, PyMAC, divergência.
4. Buffer: atual, projetado, meta/hipótese.
5. Atenções resumidas.
6. Plano Hora-Hora — elemento dominante.
7. Correlação Lots×Production Order.
8. Detail-on-demand: Lot, Material, Quantity, horários, Work Center, Order, destino, Resource não atribuído, impacto buffer, atenção de material e `Avaliar preparação`.
