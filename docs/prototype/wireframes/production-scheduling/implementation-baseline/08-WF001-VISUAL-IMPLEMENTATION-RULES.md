# WF-001 — Visual Rules
Imagem aprovada é baseline visual. Referência de diagramação: T-Systems Brasil; identidade: HIKARI industrial, premium, clean e executiva.

A imagem governa composição, hierarquia, layout e experiência, subordinada aos manifestos, decisões de domínio e baseline. Vermelho incidental não deve ser reproduzido. Termos visíveis na imagem devem ser normalizados para o pt-BR governado, e a implementação deve exibir **Cenário demonstrativo** de forma discreta e inequívoca.

Prioridades: CORE azul escuro; ESSENCIAL azul claro; IMPORTANTE laranja; COMPLEMENTAR verde. **Nunca usar vermelho.** Se houver vermelho incidental na imagem, manifesto prevalece.

Timeline deve ser o maior objeto. Evitar grid ERP, excesso de bordas e cards de peso igual. Resumo superior executivo; timeline operacional; detalhe lateral contextual. Não redesenhar unilateralmente.
