# WF-001 — Implementation Manifest
Pergunta dominante: **O que precisamos produzir?**

WF-001 materializa o Production Schedule do Balancing e sua correlação com Production Orders do PyMAC. Não é APS, execução, Dispatch List, WMS ou painel genérico.

Fluxo: `Balancing Schedule + PyMAC Orders → HIKARI Production Scheduling → Production Readiness`.

Área Produtiva é contexto global. Cenário: Fundição DC. Dados são demonstrativos e locais. O Plano Hora-Hora é o objeto visual dominante.
