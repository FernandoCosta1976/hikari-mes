# WF-002 — Responsive Behavior

**Status:** CONCEPTUAL; NO CSS AUTHORIZED

## 1440 px — Primary Composition

- usable content width approximately 1280–1320 px;
- conceptual 12-column grid;
- three eligible Resource cards side by side, four columns each;
- Lot context may use an 8/4 composition with urgency/freshness context;
- Eligibility and Readiness Summary span full width;
- comparison view may use a compact table because all three eligible Resources fit;
- opening of Resource cards should be visible above the fold after summary/context.

## 1280 px

- retain 12-column logic with smaller gutters;
- three cards may remain side by side if readable minimum widths are preserved;
- otherwise use two cards on the first row and one on the second without implying rank;
- keep card source order DC01, DC03, DC05 and state explicitly that spatial order is not recommendation;
- compact secondary metadata in the Context Bar, not the dominant question.

## 1024 px

- use a single-column or two-column card composition based on readable content width;
- do not introduce horizontal page scrolling;
- stack Selected Lot and Buffer/attention context;
- use a linear comparison view or horizontally contained semantic table with an accessible linear alternative;
- keep the scheduled interval visible in every card;
- retain Return and future Handoff actions in document order, not as a floating overlay that hides evidence.

## Content Priority

Never remove:

- dominant question;
- selected Lot and interval;
- consolidated result and explanation;
- Eligibility distinction;
- textual condition result;
- unknown/freshness warning;
- return path.

May move to detail on demand:

- complete source/timestamp detail;
- low-priority favorable dimensions;
- full ineligible explanation;
- comparison view;
- secondary Production Order metadata.

## Scroll Behavior

Vertical scroll is expected for Resource evidence and condition details. The design must not force all dimensions above the fold or compress cards into unreadable density.
