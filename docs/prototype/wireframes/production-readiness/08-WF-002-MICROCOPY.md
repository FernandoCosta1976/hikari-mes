# WF-002 — Microcopy

**Status:** CANDIDATE FOR PRODUCT OWNER REVIEW

| Context | Proposed pt-BR microcopy |
|---|---|
| Dominant question | **Temos condições de produzir?** |
| Time reference | **Avaliação para o intervalo previsto 16:43 → 17:48.** |
| Consolidated viable result | **Existe caminho viável. Há evidência demonstrativa de pelo menos uma condição possível para produzir este Lote.** |
| Consolidated no-path result | **Nenhum caminho viável foi identificado no momento. Consulte as condições por máquina.** |
| Attention | **Há condições que exigem preparação ou acompanhamento antes do intervalo previsto.** |
| Impediment | **Uma condição conhecida impede este caminho no contexto avaliado.** |
| Insufficient information | **Não há informação suficiente para concluir esta condição com segurança.** |
| Ineligible Resource | **Não elegível para este Material. As demais condições não foram avaliadas.** |
| Current-state disclaimer | **A situação atual não indica disponibilidade, prontidão ou atribuição futura.** |
| Setup required | **Troca de molde/ferramental necessária. Consulte o motivo.** |
| No Setup | **Nenhuma troca identificada no cenário avaliado.** |
| Setup unknown | **Necessidade de Setup ainda não confirmada.** |
| Maintenance clear | **Sem restrição conhecida para o intervalo avaliado.** |
| Maintenance restriction | **Restrição conhecida para o intervalo avaliado.** |
| Material available | **Material disponível no contexto informado.** |
| Staging pending | **Material disponível; abastecimento da área pendente.** |
| Freshness issue | **Uma ou mais condições utilizam informação desatualizada ou insuficiente.** |
| Comparison action | **Comparar condições** |
| Comparison disclaimer | **Comparação somente para consulta. Nenhuma máquina será selecionada ou recomendada.** |
| Demo label | **Cenário demonstrativo — não representa condições produtivas reais.** |
| Return | **Voltar ao Plano Hora-Hora** |
| Future handoff | **Continuar para organização** |
| Handoff disclaimer | **Nenhum Recurso será atribuído nesta etapa.** |

## Language Rules

- use operational language before architectural terminology;
- explain the reason instead of relying on a status badge;
- never say “melhor”, “recomendado” or “selecionado”;
- do not call lack of current production “Disponível”;
- do not call unknown data “Não pronto”;
- use **Lote** in the UI and retain `Lot` internally;
- never use red or color-only meaning.
