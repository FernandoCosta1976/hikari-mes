# HIKARI MES — Personas

**Group:** 03 — Personas, Business Questions and Use Cases  
**Status:** PROTOTYPE_BASELINE

This directory defines the human roles that interact with or consume information from the HIKARI MES prototype.

Personas are not screen-access profiles and do not define authorization. They define operational context, decisions, questions, information needs and interaction moments.

## Canonical personas

1. Operator
2. Production Leader
3. Foundry Supervisor
4. Technician
5. Manufacturing / Process Engineer
6. Quality Professional
7. Production Manager
8. Industrial Director

## Governing principle

A HIKARI experience exists to support a decision or action by a persona.

The traceability chain is:

**Persona → Business Question → Use Case → Decision → Required Information → Interaction → Experience**

No prototype screen shall be created only because information is available.
